# Nowledge Mem Gemini CLI v0.1.5

Sharper space-aware guidance for Gemini CLI.

## Summary

- Working Memory guidance now talks about spaces in plain user language instead of internal ID-shaped wording.
- Search and recall guidance now explains more clearly how Gemini should behave when one session belongs to one lane, and how shared-space retrieval still comes from Mem's own configuration.
- The shipped README now matches the same model, so installation, troubleshooting, and runtime behavior no longer drift.

## Why this release matters

These are not just external docs edits. Gemini ships `GEMINI.md` and the bundled skills as part of the extension package, so better lane guidance changes the behavior users actually get after install.

## Operational Notes

- Run `npm run verify:release` before tagging.
- Tag name: `nowledge-mem-gemini-cli-v0.1.5`.

## Install

Search `Nowledge Mem` in the [Gemini CLI Extensions Gallery](https://geminicli.com/extensions/?name=nowledge-co/nowledge-mem-gemini-cli) and install, or:

```bash
gemini extensions install github.com/nowledge-co/nowledge-mem-gemini-cli --ref nowledge-mem-gemini-cli-v0.1.5
```
