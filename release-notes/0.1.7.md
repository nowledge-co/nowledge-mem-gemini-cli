# Nowledge Mem Gemini CLI 0.1.7

This release adds a bundled local Nowledge Mem MCP server to the Gemini CLI extension.

## What changed

- Gemini can now use direct Nowledge Mem MCP tools for retrieval and memory writes, alongside the existing commands, skills, and lifecycle hooks.
- Local desktop users get the default MCP endpoint automatically.
- Remote users can define `mcpServers.nowledge-mem` in Gemini settings; user settings take precedence over the bundled local endpoint.

## Upgrade

Update the extension, restart Gemini CLI, and ask a continuation-style question such as "What did we decide before about this release?" Gemini should be able to use the Nowledge Mem tools instead of relying only on command-style guidance.
