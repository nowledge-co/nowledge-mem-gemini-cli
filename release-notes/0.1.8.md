# Nowledge Mem Gemini CLI 0.1.8

This release tightens the remote setup path for Gemini CLI.

- Durable remote credentials stay in the shared `nmem` client config.
- Remote MCP setup now points users to `nmem config mcp show --host gemini-cli`, which generates the exact `settings.json` block from the same URL and API key.
- The bundled MCP server remains local by default; user Gemini settings remain the override layer for remote Mem or custom endpoints.
